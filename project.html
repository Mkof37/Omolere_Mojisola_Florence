Case Study 1: Front-End Capstone & Interactive UI Architecture

The Problem: Users looking for responsive utility web tools often face slow interface updates, cluttered controls, and poor mobile accessibility. On the development side, building a UI without strict repository guidelines leads to messy code structures, missing environment rules, and unpredictable AI assistant behavior during development.


What I Did:

  • Designed and built a lightweight, responsive front-end unit conversion dashboard using semantic HTML5, modern CSS (Flexbox/CSS Grid), and ES6+ Vanilla JavaScript.
  • Established an AI-in-the-loop workflow by authoring a repository-level CLAUDE.md to enforce explicit code style, accessibility standards, and architecture rules for AI coding assistants.
  • Structured the repository governance from day zero with a clean .gitignore and open-source licensing before pushing to GitHub.
  • Configured a mobile-first responsive grid using CSS variables to handle light/dark thematic elements and seamless cross-device layouts.

What Came of It: Delivered a fully responsive web application with zero external framework overhead that renders and converts units instantly on input. Created a reproducible repository setup template that reduces AI prompt iteration time by providing standing context directly inside the codebase.

Case Study 2: Operational Integrity & Data Control Systems

The Problem: Manual data processing and unvalidated inputs in operational datasets frequently lead to data drift, reporting inaccuracies, and silent system errors that stall decision-making.


What I Did:

  • Served as Data Control Officer, designing input validation checks and automated monitoring scripts using Python and SQL.
  • Audited relational databases (PostgreSQL/MySQL) to catch structural inconsistencies and null-value anomalies before data pipeline execution.
  • Restructured data workflows to strictly isolate operational data control tasks, ensuring operational integrity across reporting channels.

What Came of It: Reduced data validation errors prior to reporting cycles, ensuring downstream business intelligence dashboards remained accurate and trustworthy. Standardized auditing procedures so incoming operational records are automatically flagged if they fail schema or completeness checks.

Case Study 3: AfriFit Web Portal & Technical Fitting Tool

The Problem: Fashion designers, tailors, and online clothing shoppers frequently deal with inconsistent sizing and fitting errors. Customers struggle to select styles that suit their body figures, leading to high garment alteration costs and client dissatisfaction.


What I Did:

  • Architected and pitched AfriFit, a web portal designed to assist customers in selecting figure-fitting clothing styles while helping tailors solve garment sizing challenges.
  • Designed the front-end layout and conversational AI prompt workflows to generate a simple, chat-assisted interface for customer measurement input and style selection.
  • Structured the technical roadmap for both front-end user experience and back-end fit-matching logic to handle diverse body measurements seamlessly.

What Came of It: Produced a functional project specification and AI-assisted workflow prompt that builds a lightweight version of the portal, bridging the gap between custom tailoring precision and digital style selection.
